01 / FIX THE QUESTION

先锁定这次要解决的计算问题

当前阶段只处理既有两层界面的坐标优化，不同时改变界面组成、晶面、终止面、面内晶胞和固定层策略。

固定的对象

项目记录LRM 两层 + 非晶 Li₃PO₄；288 原子；240 个可动原子、48 个固定原子；第一阶段固定晶胞。

开始前必须从实际 STRU/CIF 读取原子编号和约束，不能仅凭旧报告重建固定原子映射。

固定的标签方法

目标 DFT沿用项目的 ABACUS PBE+U、自旋极化、Mn/Co/Ni 的既定 U、D3(BJ)、赝势/轨道和数值精度。

训练标签与最终单点验收应对应同一势能面；磁态或电子态不同的结果不能未经区分地混在一起。

02 / MODEL PREFLIGHT

先证明模型“能正确运行”

checkpoint 可加载只是软件检查通过，不等于对 LRM/LPO 化学环境有效。先做小规模输入输出核验，再启动整条优化。

GATE 0

固定模型身份

对 `DPA4-Air-OMat24-v20260805.pt` 保存 SHA-256：`7ac5fb696fc057229ceebc33f31f7a96b2f3616ac5b63a512acd1848f2d41a09`，记录文件来源、DeepMD-kit 与 PyTorch 版本。

理由：保证模型、微调产物与后续结构能够追溯，避免不同 checkpoint 被当成同一个模型。

GATE 1

核验元素映射与单位

模型类型映射包含 Li、P、O、Mn、Co、Ni；逐项核对程序中的 type_map、STRU 原子顺序、晶胞、周期边界、坐标/能量/力单位和 48 个固定原子编号。

理由：错误的元素编号或单位会生成数值上可运行、物理上错误的力。

GATE 2

检查 DPA4 特有输入

确认当前 checkpoint 是否需要原子 spin/charge 输入、接口是否支持能量和力推理、是否支持 PyTorch 微调及 LoRA；记录模型卡中能核实的训练参考方法和已知精度。

理由：过渡金属磁性与 DFT+U 会影响局部势能面，不能从元素覆盖或字段名称推断模型已学到本项目的磁态。

当前状态：静态 checkpoint 检查已完成；项目环境之前未发现 `torch` 与 `deepmd`，实际推理、checkpoint 兼容性及微调接口仍待验证。先在隔离环境完成预检，不要直接覆盖 ABACUS 环境。

03 / ML EXPLORATION

用原始 DPA4-Air 做受控预优化

第一条轨迹的价值是暴露模型在当前结构附近会怎样移动原子，并形成主动学习候选，不是直接产出最终结构。

  1. 输入冻结的两层结构

    使用经过核对的 288 原子文件；不重新排序元素、不改晶胞、不改变固定层。

  2. 先做单帧力预测

    核验能量/力为有限值，固定原子受力不会推动坐标变化，并抽查界面附近力的方向和大小。

  3. 运行短程坐标优化

    限制每步最大位移，分段运行；每个优化阶段输出坐标、能量、逐原子力和优化器状态。

  4. 执行结构事件审计

    追踪 TM–O、Li–O、P–O 和 O–O 距离，界面配位数、PO₄ 完整性、LRM 层间距及原子位移。

首轮需要保存

  • 每步结构或可无损恢复的轨迹
  • 总能量、逐原子力与最大受力
  • 原子映射、约束和模型哈希
  • 局部配位与异常几何审计
  • 优化终止原因和软件版本

能量跳变、位移突增、异常短接触、P–O 拉长或 LRM 骨架破坏的帧，标记为高风险，先检查再决定是否做 DFT。

04 / QUERY SELECTION

从一条轨迹里选“有新信息”的帧

选择依据是结构或预测发生了实质变化，而不是固定每隔若干步取一帧。相邻帧高度相关，逐帧做 DFT 会产生大量冗余标签。

优先帧首轮建议选它的理由送 DFT 前检查
初始结构1 帧测得起始几何上的 ML/DFT 力差异结构文件、原子顺序、约束正确
优化早期与中期各 1–2 帧覆盖大力区和界面主要调整阶段去除相邻重复帧
后期及候选终点2 帧左右检验 ML 极小点附近的 DFT 残余力确认优化没有假收敛或结构坍塌
异常事件帧1–2 帧覆盖配位改变、大位移或模型分歧区分真实结构变化和明显非物理坏帧
小幅扰动帧1 帧起检验模型是否只记住一条优化路径扰动温和，不制造重叠/断键

可用不确定度时

若接口支持且验证过模型委员会，运行 3 个不同随机种子的微调模型，比较逐原子力差异；优先标注界面区分歧最大的构型。单模型预测差异不能冒充不确定度。

暂时没有不确定度接口时

按配位变化、异常位移、局部键长变化、ML 能量/力突变等事件筛帧。这是结构事件驱动的 DFT 在环采样，清楚记录规则即可，不宣称是严格的委员会不确定度采样。

扰动范围只是初始建议：普通原子可尝试 0.03–0.08 Å 小扰动；界面间距可少量测试约 ±0.2–0.3 Å。生成后必须做几何筛查，明显坏结构不应为了“增加数据量”而当成训练目标。

05 / DFT LABELS

DFT 单点必须同时给出可信能量和力

主动学习的新增数据不是任意计算输出，而是与目标方法一致、电子自洽收敛且原子映射可靠的能量—力标签。

固定几何 DFT 标注

  • 原子坐标和晶胞固定，不做离子步；
  • 沿用目标 PBE+U、自旋、D3(BJ)、赝势/轨道与数值精度；
  • 记录初始磁矩、最终磁态和电子占据相关设置；
  • 保存总能量、288 原子逐原子力、SCF 轨迹与输入文件。

标签进入数据集的门槛

  • SCF 达到阈值，无明显总能异常跳变；
  • 坐标、力和元素顺序一一对应；
  • 磁态/自旋分支明确，不能混淆不同电子解；
  • 记录固定原子。固定与否是优化约束，不应删除其 DFT 力标签。
SCF 未收敛的帧不做训练标签。保留它作为待诊断高风险结构；必要时使用干净电子初猜重新求解。不要把另一几何的电荷密度或 `onsite.dm` 当成一定适用的初猜。

06 / DATASET BUILD

检查数据结构和训练/验证划分

ABACUS 输出转换后，先检查数据完整性，再启动训练。原子顺序一致是跨帧训练的硬条件。

system = dpdata.LabeledSystem("path/to/abacus_scf", fmt="abacus/scf") system.to("deepmd/npy", "dataset_round00") # 转换后人工/脚本检查： # 288 atoms per frame; same atom order and type_map # finite energy/force; correct cell and units # SCF-converged labels only; fixed-atom mask kept in manifest

数据核查项

检查 `type.raw`、`type_map.raw`、坐标、晶胞、能量和力数组形状；帧数、288 原子计数、元素顺序一致；无 NaN/Inf；每帧 SCF 收敛状态可追踪。

防止验证集泄漏

按结构或阶段留出验证帧，不能把同一轨迹的相邻帧随机拆到训练和验证两边。验证集用于模拟模型面对“未参与拟合的构型”。

07 / FINE-TUNING

小数据阶段先验证 LoRA 微调

DPA4-Air 是否能按当前 DeepMD-kit 版本接受这份 checkpoint 微调，需以环境实测为准。下面配置仅是流程示意，不能未经版本核对直接当作生产输入。

推荐的首轮策略

若 checkpoint 与当前工具版本兼容，先用 LoRA 对界面数据微调，减少小数据对通用预训练权重的整体扰动。保留未微调模型作为基线。

同步比较训练集和结构留出验证集上的能量误差、全体系力误差，以及界面 TM/O/P/Li 分组力误差。

不要只看训练损失

训练误差下降只说明模型更贴合已见样本。若验证误差增大、界面最大力误差偏大，或微调后结构出现新异常，表示当前数据覆盖不足或有过拟合风险。

当 LoRA 不能改善且已有多种可靠界面标签后，再评估全参数微调/重训。

08 / ACTIVE LEARNING CYCLE

每一轮做什么，何时回到 DFT？

每轮只新增少量去重后的高信息结构；然后重新优化，观察误差是否转移或改善。

继续采样并更新

DFT 与 ML 在界面原子力上差异较大；出现未见配位；微调验证集误差仍高；或候选结构在 DFT 下最大受力未达标。按失效环境补帧，完成下一轮标注和微调。

进入最终结构验收

轨迹局部结构稳定、验证误差不再明显变化，且新模型优化得到合理候选。此时停止训练判定仍不是结构通过；必须做干净的目标 DFT 单点求受力。

每轮规模：第一轮建议 8–12 个代表帧建立基线；后续每轮新增约 3–6 个高信息帧作为预算起点，而非固定配额。若 SCF 标签困难或结构重复，应缩减或调整样本。

09 / DFT ACCEPTANCE

决定结构是否能进入电子性质计算

验收在冻结 ML 几何上进行，使用与最终性质相同的目标 DFT 方法。固定原子的力单独报告；几何阈值应用于可动原子。

GATE 01

电子自洽

SCF 收敛、达到目标阈值、无异常能量跳变；磁态和占据可复核。

GATE 02

DFT 残余受力

240 个可动原子最大受力分量 ≤ 0.05 eV/Å。记录全部力向量，固定原子另列。

GATE 03

局部几何合理

检查 PO₄、LRM 层状骨架、TM–O/Li–O 接触和异常短距离；避免只用单一最大力指标。

未通过时

若电子收敛但残余力过大：把收敛的 DFT 力作为新标签，定位误差原子和局部环境；再微调/优化，或从该候选开始短程 DFT 几何细化。

通过后

冻结通过验收的几何，按一致晶胞、坐标映射和计算参数开展差分电荷、DOS/PDOS 与结合能计算。它仍代表该局部模型和约束，不等于宏观包覆层的全部行为。

FIRST PILOT

建议的第一轮试点交付

先回答工具兼容性和误差是否可改善，再决定是否扩展训练投入。
